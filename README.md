# 衛星データ解析のための GT・DEM・LULC データセット一覧

衛星データ解析に使える正解・学習データ(GT)、標高データ(DEM)、土地被覆図(LULC)の一覧です。毎月1日に自動で更新されます。

**一覧はこちら → [output/datasets.csv](output/datasets.csv)**

画面上で検索・絞り込みができます。右上のダウンロードボタンから保存して、Excelでも開けます。

## 注意

- 「商用利用(自動判定)」の列は、ライセンス表記からの機械的な推定です。利用の前に、必ず入手先で原文を確認してください。
- 一覧は、TorchGeo、Microsoft Planetary Computer、Zenodo、Hugging Face の公開情報から自動で作成しています。
